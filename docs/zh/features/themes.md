# 🎨 丰富的主题库

Music Tagger 内置大量精心设计的主题，可在侧边栏一键切换，无需刷新页面。

## 概览

主题全局生效并跨会话持久保存。每款主题均针对可读性和视觉一致性进行了精调，覆盖所有视图。

### 主题分类

| 分类 | 说明 |
| --- | --- |
| **深色** | 低光环境下的深色背景主题 |
| **浅色** | 白天使用的简洁明亮界面 |
| **高对比度** | 以无障碍为核心，对比度最大化 |
| **彩色** | 以鲜明强调色为主的活泼配色 |

## 如何切换主题

1. 打开**侧边栏**（左上角汉堡菜单图标）。
2. 点击侧边栏底部的**主题**调色板图标。
3. 在主题网格中浏览，点击任意色块即可立即应用。

## 自定义主题

通过 CSS 变量覆盖实现自定义主题功能已在规划中，将于未来版本提供。主题系统基于 CSS 自定义属性构建，非常易于扩展。
