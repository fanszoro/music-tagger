# 🗂️ 文件健康检测

通过 Music Tagger 的自动化文件健康工具，保持音乐库整洁一致。

## 丢失文件扫描

检测数据库中存在但音频文件已不在磁盘上的音轨——通常发生在手动移动、重命名或删除文件之后。

### 如何运行

1. 导航至**音乐库 → 文件健康**。
2. 点击**扫描丢失文件**。
3. 查看结果列表，每行显示数据库记录及最后已知路径。

### 可用操作

| 操作 | 说明 |
| --- | --- |
| **重新定位** | 手动将记录指向新的文件路径 |
| **自动匹配** | 让系统按文件名或指纹搜索 |
| **删除记录** | 清除孤立的数据库条目 |

## 重复文件检测

通过两种检测方法发现完全重复及近似重复的文件：

| 方法 | 原理 |
| --- | --- |
| **元数据相似度** | 匹配标题 + 艺术家组合完全相同的音轨 |
| **音频指纹** | 使用声学指纹技术，无论格式或码率均可检测相同音频 |

### 重复处理操作

- **保留最高质量** — 自动选择最高码率/格式的文件，其余标记为待删除。
- **手动审查** — 并排对比两个副本，选择保留哪一个。
- **合并标签** — 将两个副本中最佳的元数据合并到保留文件上。

## 路径修复

重新整理音乐目录结构后，使用路径修复一次性更新所有数据库记录。

1. 点击**音乐库 → 路径修复**。
2. 输入**旧路径前缀**和**新路径前缀**。
3. 预览受影响的记录。
4. 确认后批量应用路径更新。
