# 🎨 Rich Theme Gallery

Music Tagger ships with a broad collection of hand-crafted themes — switchable instantly from the sidebar without any page reload.

## Overview

Themes are applied globally and persist across sessions. Each theme is carefully tuned for readability and aesthetic consistency across all views.

### Available Theme Categories

| Category | Description |
| --- | --- |
| **Dark** | Deep backgrounds for low-light environments |
| **Light** | Clean, bright interfaces for daytime use |
| **High Contrast** | Accessibility-focused with maximum contrast ratios |
| **Coloured** | Vibrant accent-driven palettes |

## How to Switch Themes

1. Open the **Sidebar** (hamburger icon, top-left).
2. Click the **Theme** palette icon at the bottom of the sidebar.
3. Browse the theme grid and click any swatch to apply instantly.
